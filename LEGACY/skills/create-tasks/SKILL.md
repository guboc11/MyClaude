# 태스크 생성

요구 사항을 구현할 태스크를 원자 단위로 세부 생성한다. 각 태스크 description에:
- 어떤 파일을 어떻게 바꾸는지, 영향 받는 사용처.
- 완료 조건을 **검증 가능한 명령으로** 적는다 — rg/grep으로 실제 파일에 변경이 있는지 + 실제 화면·경로에서의 동작(E2E). "~하면 완료" 식 모호한 표현 금지.
- "실제 폼·화면·기능"을 지목한다. 테스트 패널·임시방편·보조물로 대체될 여지를 남기지 않는다.

선행 결정이 필요한 갈림길(설계·범위·외부 의존)은 맨 앞 **결정 태스크**로 두고, 확정 전 의존 태스크를 막는다(blockedBy). 미정 위에 코드를 쌓지 않는다.

3~5개 태스크마다 검증 태스크를 삽입한다. 검증은 (a) 직전 코드를 Fable 5에게 리뷰받고, (b) **실제 사용자 경로**(테스트 입구가 아니라)에서 동작을 확인한다. 통과 못 하면 다음 태스크를 시작할 수 없다.

마지막 태스크는 "빌드 + 최종 검증"이다. tsc/테스트로 에러를 전부 잡고, "못 한 것"을 먼저 적은 정직한 최종 보고를 한다.
