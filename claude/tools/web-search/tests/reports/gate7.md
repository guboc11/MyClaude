## 앞의 게이트들과 다른 점

0~6번은 만들면서 재는 시험이었다. 이것은 **이미 일어난 일을 뒤에서 감사한다.**
시나리오 A·B·C 가 남긴 진짜 workspace 세 곳을 열어, 장부와 파일이 같은 말을 하는지,
워커들이 서로의 일감을 밟지 않았는지, 오류마다 되짚을 자리가 있는지를 본다.

**새로 수집하지 않는다. 네트워크도 부르지 않는다** — 감사가 대상을 바꾸면 그건 감사가 아니다.
마지막 항목이 그 사실을 스스로 판정한다.

```
node tests/gate7.mjs --project <프로젝트>
node tests/gate7.mjs --project <프로젝트> --json
```

## 이 감사가 확인하지 않은 것

- **조사 목표를 이뤘는지는 판정하지 않는다.** 그건 상위 에이전트가 할 일이라고 계획서가
  정했고, 이 게이트도 그 선을 지킨다. 대신 "기계가 완료를 말하지 않는가" 만 본다(G7-10).
- **판정이 옳은지는 보지 않는다.** 이름표가 맞게 붙었는지는 사람이 볼 일이다.
  시나리오 B 보고서가 자기 판정 하나가 성급했다고 적어 둔 것이 그 예다.
- **시나리오 C 에는 판정이 없다.** 되찾기만 재는 연습이라 그렇게 두었고, G7-3 은
  "둘 이상인 곳이 두 곳" 으로 통과한다.
