# onboarding(MCP) — 매뉴얼

## 이름

**onboarding** — 규칙·구조 문서(README.md)를 조항 단위로 조회하는 읽기 전용 MCP 리모컨

## 형식

```
topics ()
list   (doc)
search (doc, query)
read   (doc, ids)
```

## 설명

CLAUDE.md가 지정한 규칙·구조 폴더(`_` 접두 폴더)의 README.md를 관할한다.
문서를 헤더 단위로 파싱해 조항 주소로 반환한다. 조회 시점 실시간 파싱(캐시 없음),
읽기 전용(쓰기 도구 없음). 도구 매뉴얼(MANUAL.md) 등 일반 문서는 관할 밖 — Read로 읽는다.

용법 3형: **온보딩** `read("AUDIT", ["definition"])` / **리마인드** `read("AUDIT", ["2-3"])` / **탐색** `search` → `read`.

## doc 인자 해석 (공통)

해석 순서:

| 순서 | 입력 | 해석 |
|---|---|---|
| ① | 주제명 (예: `"AUDIT"`) | 자동 발견된 주제의 README.md (아래 topics 참조) |
| ② | 절대경로 | 그대로 사용 (관할 밖 문서도 조회 가능한 특수 케이스) |
| ③ | 상대경로 | `$CLAUDE_PROJECT_DIR` 기준 (미설정 시 cwd) |
| — | 폴더 경로였다면 | 그 안의 `README.md`로 확정 |
| — | 최종 파일 없음 | 에러: `문서를 찾을 수 없음: <경로>` + 등록된 주제 목록 동봉 |

## 도구

### topics()

관할 주제 목록. 인자 없음.

- 발견 규약: **프로젝트 루트의 `_` 접두 폴더 중 `README.md`를 가진 것** — 등록 절차 없음.
  폴더에 README를 만들면 그 순간 주제가 된다. 주제명 = 폴더명에서 `_` 제거.

반환 형식:

```
관할 주제 (프로젝트: <루트>):
- AUDIT  (_AUDIT/) — _AUDIT — 감사·수사 기록
```

주제가 없으면: `관할 주제 없음 (...)` + 등록 방법 안내.

### list(doc)

문서의 조항 목차를 반환한다.

| 인자 | 타입 | 필수 | 설명 |
|---|---|---|---|
| doc | string | ✓ | 주제명 또는 경로 (해석 표 참조) |

반환 형식:

```
문서: <제목>
- definition (기본 섹션)
- 1 <제목>
  - 1-1 <제목>
```

주소 있는 조항이 없으면: `<제목>: 주소 있는 조항이 없습니다 (definition 또는 번호 헤더 필요)`

### search(doc, query)

키워드가 등장하는 조항의 주소를 찾는다. 대소문자 무시, 부분 문자열 매칭.

| 인자 | 타입 | 필수 | 설명 |
|---|---|---|---|
| doc | string | ✓ | 주제명 또는 경로 |
| query | string | ✓ | 검색 키워드 (공백만 있으면 에러) |

반환 형식 (조항당 매칭 줄 최대 3개):

```
"<query>" 매칭 조항:

[2-1] 명명
  · <매칭된 줄>
```

매칭 없음: `"<query>" 매칭 없음.` + 목차 전체.

### read(doc, ids)

조항 본문을 반환한다. **부모 주소는 하위 조항(예시 포함)까지 통째로 반환한다.**

| 인자 | 타입 | 필수 | 설명 |
|---|---|---|---|
| doc | string | ✓ | 주제명 또는 경로 |
| ids | string[] | ✓ | 조항 주소 배열. 빈 배열이면 에러 |

주소 규칙:

| ids 값 | 반환 범위 |
|---|---|
| `"all"` | **문서 전체** (제목 포함 원문 통째 — 예약 주소) |
| `"definition"` | definition 섹션 + 그 하위 무주소 헤더 전부 |
| `"1"` | 1장 통째 (1-1, 1-1-1, ... 전부) |
| `"1-1"` | 1-1 + 자식들 (1-1-1, 1-1-2) |
| `"1-1-1"` | 그 조항 하나 |
| 복수 (`["1-1","2-3"]`) | 각 블록을 `---` 구분자로 이어 반환 |

하나라도 없는 주소가 있으면 **아무것도 반환하지 않고** `없는 주소: <목록>` + 목차 전체를 반환한다.
성공한 read 호출은 usage.jsonl에 기록된다 (아래 파일 절 참조).

## 대상 문서 문법 (파서 계약)

| 요소 | 판별 규칙 | 취급 |
|---|---|---|
| 제목 | 문서에서 처음 만나는 헤더 (급 무관) | 주소 없음. list에 문서명으로만. 제목 아래 직접 내용 금지 |
| definition | 헤더 텍스트가 정확히 `definition` | 예약 주소 `definition`. 온보딩 진입점 |
| 번호 조항 | 헤더 텍스트가 `숫자(-숫자)*` + 공백 + 제목 | 번호가 곧 주소. 헤더 급(#·##·###)과 번호 깊이를 일치시킬 것 |
| 무주소 헤더 | 위 셋 다 아님 (예: `## 시작하는 법`) | 부모 섹션 본문의 일부. 직접 조회 불가 |
| 코드 블록 | ``` 로 여닫는 범위 | 내부의 `#` 줄은 헤더가 아님 |
| 섹션 범위 | 해당 헤더 ~ 다음 같거나 얕은 급 헤더 직전 | 부모 조회 = 서브트리 통째의 근거 |

제약: 조항 번호는 문서 내 유일해야 한다. 번호 개편은 조항 주소(리모컨 버튼)를 바꾸는
파괴적 변경이므로, 참조하는 쪽(CLAUDE.md·훅·다른 문서)과 함께 갱신할 것.

## 진단 (에러 메시지 전체)

| 메시지 | 원인 | 대처 |
|---|---|---|
| `doc이 필요합니다 — 주제명(...) 또는 경로 ...` | doc 누락 | 주제명 또는 경로 전달 |
| `문서를 찾을 수 없음: <경로>` + `등록된 주제: <목록>` | 주제명 오타·파일 부재 | 동봉된 주제 목록 확인, 또는 경로 확인 |
| `ids 배열이 필요합니다 (...)` | ids 누락·빈 배열·비배열 | `["definition"]` 형태로 전달 |
| `query가 필요합니다` | 검색어 누락·공백 | 키워드 전달 |
| `없는 주소: <목록>` + 목차 | 오타·개편된 번호 | 동봉된 목차에서 주소 재확인 |
| `알 수 없는 도구: <이름>` | topics/list/read/search 외 호출 | 도구명 확인 |

## 파일

| 경로 | 역할 |
|---|---|
| `~/.claude/tools/onboarding-mcp/server.mjs` | 서버 본체 (무의존성 stdio, 약 250줄) |
| `~/.claude/tools/onboarding-mcp/usage.jsonl` | read 사용 기록. 1줄 = `{"ts","doc","ids"}` |
| `~/.claude/tools/onboarding-mcp/MANUAL.md` | 이 문서 (원본) |
| `<repo>/.claude/tools/onboarding-mcp/MANUAL.md` | 팀 공유 사본 |

usage.jsonl은 "자주 재주입되는 조항" 신호다 — 그 조항은 표현 교정 또는 훅 승격 후보
(재주입은 처방, 표현 교정이 치료).

## 설치

```
claude mcp add onboarding --scope user -- node ~/.claude/tools/onboarding-mcp/server.mjs
```

user 스코프 (전 프로젝트 공용). 도구 노출은 등록 후 **새 세션부터**.
서버 코드 수정 후에는 MCP 재연결(/mcp)이 필요하다 (장기 실행 프로세스).

## 예시

```
topics()
→ 관할 주제 (프로젝트: .../dibang):
  - AUDIT  (_AUDIT/) — _AUDIT — 감사·수사 기록

read("AUDIT", ["definition"])
→ # definition ... ## 시작하는 법 ... (온보딩 통째)

search("AUDIT", "소급")
→ [2-4] 반복·보수  · 닫힌 주제를 소급 수정하지 않는 이유: ...

read("AUDIT", ["2-1", "2-4"])
→ 명명 규칙과 반복·보수 조항만 재주입 (--- 구분)

read("AUDIT", ["all"])              ← 문서 전체 보기
read("/abs/path/_AUDIT", ["definition"])   ← 관할 밖 문서도 절대경로로 조회 가능
read("AUDIT", ["9-9"])
→ 없는 주소: 9-9  (+ 목차)
```
