# Intent — 의도 확인 스킬

사용자는 짧고 모호하게 말한다. 이 스킬의 역할은 그 짧은 입력을 대화 맥락 기반으로 상세하게 풀어서 보여주고, 사용자의 확인을 받은 뒤 실행하는 것이다.

## 왜 이 스킬이 필요한가

무거운 작업(파일 생성, 대규모 리팩토링, 리서치 정리 등)을 시작하기 전에 클로드가 사용자의 의도를 정확히 이해하고 있는지 확인하지 않으면, 잘못된 방향으로 토큰을 낭비하게 된다. 이 스킬은 실행 전 "의도 정렬" 단계를 강제해서, 한 번에 맞는 결과를 내도록 돕는다.

## 흐름

### 1단계: 입력 수신

사용자가 `/intent` 뒤에 짧은 지시를 붙인다.

**예시:**
- `/intent 그거랑 전에 했던거 합쳐서 정리해줘`
- `/intent 불변 규칙 빠진거 없는지 점검하고 업데이트`
- `/intent 클래스 다이어그램 수정해야 할 것 같은데`

### 2단계: 맥락 기반 확장

대화에 이미 존재하는 맥락(최근 대화 흐름, 언급된 파일, 진행 중인 작업)을 기반으로 사용자의 짧은 입력을 상세하게 풀어쓴다. 자연스러운 문장으로, 내가 이해한 바를 그대로 말하듯이 쓴다.

채워야 하는 것들:
- **무엇을**: 구체적으로 어떤 대상에 대한 작업인지
- **어떻게**: 어떤 방식으로 작업할 것인지
- **범위**: 어디까지 건드리는지
- **맥락**: 왜 이 작업이 지금 필요한지

모호한 부분이 있으면 추측하지 말고 "이 부분은 ~인지 ~인지 확인이 필요해요"라고 명시한다.

**출력:**

```
이렇게 이해했어요:

[3~8문장의 자연스러운 설명]

이런 얘기 맞나요?
```

### 3단계: 수정 루프

사용자가 수정 사항을 주면 반영해서 다시 보여준다. 사용자가 확정할 때까지 반복한다.

사용자가 "맞아 해줘", "응 그거야 진행해", "ㅇㅇ 고", "실행해줘" 같이 실행 의사를 표현하면 4단계로 넘어간다.

### 4단계: 실행

확정된 내용을 그대로 작업 지시로 받아서 같은 대화 안에서 바로 수행한다.

## 주의사항

- 대화 컨텍스트만 사용한다. 사용자가 명시적으로 요청한 경우에만 추가 파일을 읽는다.
- 확장 프롬프트는 3~8문장. 사용자가 빠르게 훑을 수 있어야 한다.
- 톤은 대화체. "이런 거 맞지?" 하고 확인하는 느낌.
